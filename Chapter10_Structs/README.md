# C语言结构体综合考核特训 (Struct Comprehensive Practice)

本仓库记录了大一C语言学习阶段的结构体综合练习，包含数组、指针、函数与结构体的混合应用。

## 代码目录
- `1.c`：图书查找系统。练习结构体数组作为函数参数，打擂台查找最大值的下标。
- `2.c`：学生成绩加分。练习结构体指针作为函数参数，以及通过指针修改结构体成员（`->`）。
- `3.c`：迷你学生管理系统。综合练习：结构体数组、菜单循环（`while(1)`）、增删改查逻辑、以及结构体整体交换（冒泡排序）。

## 核心踩坑记录 (Lessons Learned)

1. **`scanf` 与字符数组的死坑**：
   - 结构体里的 `char name[20]` 是字符数组，数组名本身就是地址。所以在 `scanf` 中，`name` 前面**绝对不能加 `&`**；但普通的 `int` 或 `float` 变量前**必须加 `&`**。如：`scanf("%s %d", stu.name, &stu.score);`

2. **死循环菜单的刷新**：
   - 在 `while(1)` 的菜单系统中，`scanf("%d", &choice)` 必须放在循环体内！如果放在外面，程序会卡死在一个操作上无限循环。

3. **变量作用域灾难**：
   - 记录学生人数的 `count` 变量，必须定义在 `main` 函数的 `while` 循环外面。如果定义在 `if` 分支里面，每次循环都会被重新初始化，导致数据全部丢失。

4. **结构体整体交换**：
   - 结构体变量可以直接使用 `=` 进行整体赋值。所以在冒泡排序交换时，可以直接定义 `struct student t;`，然后 `t = stu[j]; stu[j] = stu[j+1]; ...`，不需要逐个成员去交换。
