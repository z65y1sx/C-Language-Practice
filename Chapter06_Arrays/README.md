### 第六章：数组 (Chapter06_Arrays)
- `01_array_max_sum.c`：输入5个数，求总和与最大值（练习数组遍历与打擂台算法）。
- `02_array_reverse.c`：输入5个数，逆序输出（练习数组下标递减遍历）。
- `03_array_positive_negative.c`：输入5个数，统计正数和负数的个数（练习数组与条件分支结合）。

#### 核心踩坑记录 (Important Notes)
1. **求和的初始化陷阱**：在找最大值和求和时，如果循环从 `i=1` 开始，必须把第一个元素 `a[0]` 赋给 `sum` 和 `max` 作为初始值，否则会漏掉第一个数。
2. **数组越界死穴**：定义一个长度为 5 的数组 `a[5]`，其合法下标是 `0~4`。`for` 循环遍历的终止条件必须是 `i < 5`，绝对不能写 `i <= 5`，否则会造成数组越界。
3. **输出排版规范**：连续打印数组元素时，要在 `printf` 的格式符里加上空格（`%d `），防止输出结果连成一坨，影响可读性和阅卷体验。
