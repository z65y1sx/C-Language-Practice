##  核心踩坑记录 (Important Notes)

1. **`scanf` 的夺命 `&`**：写 `scanf` 忘记加 `&` 导致程序读入乱码或输出空气。**教训：敲下 `scanf` 四个字母，必须立刻补上 `&`！**
2. **`do-while` 的死循环**：把 `scanf` 写在了 `do-while` 外面，导致输入错误后无限打印“密码错误”。**教训：需要反复输入的交互，`scanf` 必须放循环体内。**
3. **`for` 循环的 C89 标准**：在老版本编译器下，不能在 `for()` 括号内直接写 `int i = 0;`，必须在函数开头先声明。
4. **判断素数的边界**：判断素数时，默认 `isprime = 1`，但必须特殊处理输入为 `1` 或负数的情况（它们不是素数）。
