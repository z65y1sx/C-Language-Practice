# Chapter10_Struct_Advance

## 题目

输入 5 个学生的学号和成绩：

- 成绩小于 60，加 5 分
- 成绩大于等于 90，减 5 分
- 再按学号从小到大排序，输出最终结果


## 关键点

- 指针遍历两种等价写法：`p[i].score` 和 `(p+i)->score`，括号不能省
- 交换必须三步加一个临时结构体，不能直接赋值覆盖
- 改分顺序：59 先加 5 变 64，不会误触 90 分支，安全


## 踩坑记录

- `p[i].name`为字符数组在`scanf`里前面不能加`&`
- 输出时不能直接使用`*(p+i)`这样会输出结构体数组整体导致输出乱码
