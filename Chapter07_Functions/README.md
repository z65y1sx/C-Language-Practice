### 第七章：函数 (Chapter07_Functions)
- `01_max_function.c`：利用三目运算符求两个数的最大值（练习带返回值的函数）。
- `02_factorial_function.c`：求一个数的阶乘（练习函数内部循环及返回值）。
- `03_find_max_array.c`：求数组中的最大值（练习数组传参，防止数组退化）。

#### 核心踩坑记录 (Important Notes)
1. **数组传参退化**：在 C 语言中，把数组作为函数参数时，数组名会退化为指向首元素的指针。因此，**必须额外传入一个 `n` 来表示数组长度**，函数内部不能用 `sizeof` 求长度。
2. **函数返回值**：定义了 `int` 类型的函数，内部必须要有 `return` 返回对应的值；如果是不需要返回值的函数，必须声明为 `void`。
