# Chapter12_FileIO


## 代码目录
- `01_mini_student_system2.c`：为结构体章节中的迷你学生管理系统的第二版，拥有了文件操作持久化功能。
- `02_score_append.c`：成绩追加，在添加5个人并保存之后再次追加3个人并算出平均分。


## 踩坑记录
1. **结构体变量**：
   - 定义结构体变量应在结构体之后，C语言是从上向下读，先定义结构体变量则会报错。


2. **读取学生的逻辑错误**:
   - 在`while (count < 100 && fscanf(fp, "%s %d", stu[count].name, &stu[count].score) == 2) `中应当等于2，否则只会读到前半段的名字。
